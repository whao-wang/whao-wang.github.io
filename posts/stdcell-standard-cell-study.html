一句话理解
标准单元（standard cell）是把常用逻辑门做成具有统一高度、可拼接的版图模块。所谓 6T/7.5T，描述的是单元在一个参考金属层的布线间距（pitch）尺度上有多高，并不是只有 6 根金属线，更不是只有 6 层金属。

1. 先把三个概念分开

1.1 Metal layer：Z 方向的“楼层”

芯片不是一个平面，而是硅片上方叠着多层金属：

        M4  ───────────────────
        M3  ───────────────────
        M2  ───────────────────
        M1  ───────────────────
        M0  ───────────────────
          contact / transistor
        ────────────────────────  silicon

不同金属层位于不同的 Z 高度。因此，M1 和 M2 在 XY 俯视图中可以占据同一位置、互相交叉；只有放置 via，它们才发生电气连接。

M1：       │
           │
M2：  ─────●─────   ● = via，表示上下层导通
           │

没有 via 时，交叉只是“空间上重叠”，不是电路上的连接。

1.2 Routing track：某一层内部的“车道”

在同一层金属上，布线仍然要遵守固定的网格。每一条合法的中心线位置可以理解为一条 track：

M2 track 1  =====================
M2 track 2  =====================
M2 track 3  =====================
M2 track 4  =====================
M2 track 5  =====================
M2 track 6  =====================

所以：

概念 方向 解决的问题
metal layer Z 方向 有几层楼可以布线？
routing track 某一层的 XY 网格 这一层有多少条合法车道？
via Z 方向连接 如何在楼层之间换层？

2. 标准单元是什么

标准单元是预先设计、验证并抽象成库的逻辑模块，例如：

  • INV：反相器
  • NAND2：二输入 NAND
  • NOR2：二输入 NOR
  • DFF：触发器
  • BUF：缓冲器

它们通常具有统一的 cell height，左右边界可以像积木一样拼接。综合工具决定“用哪些逻辑门”，布局布线工具再把这些单元放到行（row）中，并连接它们的输入、输出、电源和地。

VDD rail  ─────────────────────────
           [ INV ][ NAND2 ][ DFF ]
VSS rail  ─────────────────────────

统一高度的价值是：布局工具可以把大量单元快速排成规则的行，而不必为每个逻辑门重新解决整体高度问题。

3. 6T 到底在量什么

在先进节点的标准单元讨论中，常用某个局部金属层（很多语境下是 M2）的 routing pitch 作为参考。

cell height ≈ track count × reference-metal pitch

例如，假设参考金属层 pitch 为 24 nm：

6T cell height ≈ 6 × 24 nm = 144 nm

这表示：在单元的 Y 方向高度内，大约容纳 6 个该参考层的布线 pitch。它不表示：

  • 只有 6 根金属线；
  • M1 到 M6 只有 6 层；
  • 所有金属层合计只有 6 个位置；
  • 单元内部的每个信号都只能占一条“全局车道”。

一个更准确的空间想象是：

                  cell width
        ←────────────────────────→
        ┌────────────────────────┐
 M2     │========================│  track 1
        │========================│  track 2
        │========================│  track 3
        │========================│  track 4
        │========================│  track 5
        │========================│  track 6
        └────────────────────────┘
                  ↑
              cell height

其他金属层仍然可以在相同的 XY 区域中叠加，只是各层有各层的设计规则、方向偏好和容量限制。

4. 为什么不能“把所有东西都放到更高层”

这是真正的关键问题。不同层可以重叠，并不意味着任意信号都可以随意改道到 M8、M9。

4.1 晶体管附近的局部连接绕不开

一个 NAND 门的输入、输出、电源和地，首先要从晶体管引出来：

transistor
    ↓
 contact
    ↓
 M0 / M1       局部连接
    ↓ via
 M2 / M3       单元内、单元间连接
    ↓
 M4 及更高层   更长距离的信号、时钟或电源

不能直接从晶体管跳到 M8，因为中间仍然需要 contact 和一串 via。via 本身占据 XY 面积，也会造成 blockage。

4.2 高层跳转的代价

把局部连接不断抬高，通常会增加：

  • 面积：contact、via 和 landing pad 需要空间；
  • 电阻：更长的垂直/水平路径带来额外串联电阻；
  • 电容与延迟：金属、via 和邻近耦合会改变 RC；
  • 拥塞：via 会挡住同层及相邻层的其他路径；
  • 可靠性压力：电迁移、热和工艺窗口更难控制。

因此，芯片布线更像“多层立交桥”，而不是“有无限楼层就可以把所有车都赶到顶层”。每层的车道仍然有限，换层也有成本。

5. 为什么不同层通常有不同分工

下面只是便于建立直觉的粗略分工，具体层号会随工艺和 PDK 改变：

晶体管附近       M0 / M1       contact、局部连接
标准单元附近     M2 / M3       cell 内和 cell 间信号
更远距离         M4 / M5 ...   长距离信号、时钟、局部电源
更高金属层       top metal     全局电源、时钟骨干、长距离互连

不要把这张表当成固定规则。真正应该记住的是：

越靠近晶体管的连接越难“整体搬到高层”，因为它受 contact、via、局部拥塞和 RC 的共同约束。

5.1 金属层之间的经典工程交换

可以把整套 BEOL（后端互连）想象成一座城市的立体交通系统。它并不是简单地“越高越好”，而是在三个目标之间做交换：

密度、RC 延迟、大电流能力。

越靠近晶体管，越强调“能不能密集地接出来”；越往上，越强调“能不能传得远、传得快、扛得住电流”。

区域 城市类比 典型特点 更适合
M0/M1 巷子、支路 线细、pitch 小、密度高、单位长度电阻大 transistor、source/drain、gate、cell pin 的局部连接
M2/M3 城市主干道 密度略低、线稍宽、RC 更好 cell 内和邻近 cell 之间的连接
M4/M5 及以上 高速公路 线更宽更厚、pitch 更大、单位长度电阻更低 模块级、长距离信号
顶层金属 高压输电网 最宽、最厚、最稀疏、载流能力强 全局电源、时钟骨干和关键全局网络

金属线的一个简化电阻关系是：

\[ R = \rho \frac{L}{W \cdot T} \]

其中：

  • \(L\) 是线长，越长电阻越大；
  • \(W\) 是线宽，越宽电阻越小；
  • \(T\) 是线厚，越厚电阻越小；
  • \(\rho\) 是材料的电阻率。

因此，用 M1 那种细而薄的线跑很远，会形成：

细 + 长
  ↓
R 很大
  ↓
RC delay、IR drop、信号延迟和 EM 风险都变差

这就是为什么长距离信号天然希望逐渐上移到更高层；而高层金属也会故意做得更宽、更厚、pitch 更大——它们牺牲布线密度，换取低电阻和高载流能力。

5.2 为什么不能让所有信号都直接跳到高层

晶体管在最下面。如果一个局部信号要去 M6，通常必须经过一串 contact 和 via：

transistor
    ↓
 contact
    ↓
 M0
    ↓ via
 M1
    ↓ via
 M2
    ↓ via
 M3 ... M6

如果只是连接相邻 NAND 门，却“上去 5 层、走一小段、再下来 5 层”，就像去隔壁便利店先上高速、开 50 米、再下高速：不但没有获得长距离传输的好处，还额外付出了 via、面积、延迟和拥塞代价。

所以通常是：

A cell → 邻居 cell          M1 / M2 / M3
一个模块 → 另一个模块       M4 / M5 / M6
Clock / Power / global nets  更高层金属

5.3 布线拥塞也在推动“下密上疏”

标准单元区域里有大量 cell，每个 cell 可能都有 A、B、Y、CLK、RESET 等 pin。低层必须把极多的局部连接接出来，因此需要很小的 pitch；如果低层 pitch 太大，最直接的后果就是 pin 接不出来。

到了高层，信号数量相对少很多，留下来的主要是长距离、时钟、电源和其他重要 global nets。此时牺牲密度、换取更宽更厚的金属，反而是更合理的分配。

Top metal   ═══════════════  POWER / CLOCK：最宽、最厚、最稀
M6          ═══════════════  global routing
M5          ═══════════════  long routing
M4          ───────────────  module routing
M3          ─── ─── ─── ───  cell-to-cell
M2          ─ ─ ─ ─ ─ ─ ─ ─  local routing
M1          │││││││││││││││  超密局部连接
            █ █ █ █ █ █ █     transistors

最终可以把 BEOL 的分层逻辑压缩成两句话：

  • 低层解决：我怎样把海量晶体管和 cell pin 密集地接出来？
  • 高层解决：我怎样把信号和电源跨很远送过去，同时不要太慢、不要掉压？

这两个目标天然矛盾，所以金属层必须形成从“高密度、较高单位长度电阻”到“低密度、低单位长度电阻和高载流能力”的梯度。

6. 6T 变矮后，为什么会变难

降低 track count 的目标是让标准单元更矮，从而提高单位面积的逻辑密度。但高度变矮后，以下资源都会变紧：

  1. 电源轨和地线需要占空间；
  2. 输入、输出以及内部晶体管连接需要引出；
  3. 不同网络需要满足间距、线宽和 via enclosure 规则；
  4. 相邻单元之间需要共享或避让边界资源；
  5. 局部布线拥塞可能让“逻辑上可行”的门无法完成物理实现。

所以 6T 并不是简单地把 7.5T 的高度裁掉 20%。它往往需要同时改进晶体管布局、接触方式、局部互连和供电结构。

7. 与 buried power rail、背面供电的关系

当标准单元正面空间越来越拥挤时，一个思路是把电源传输从正面布线资源中移走：

  • Buried Power Rail（BPR，埋入式电源轨）：把部分电源轨埋入器件或衬底附近，减少正面金属层的占用；
  • Backside Power Delivery（背面供电）：从晶圆背面为晶体管提供电源，减轻正面信号布线与电源布线的冲突。

这就是为什么讨论 6T/5T 标准单元时，经常会同时提到 BPR 和 backside power：它们不是“凭空增加 track”，而是在重新安排供电和信号所使用的物理资源。

8. 最后形成一张脑内地图

标准单元 = 统一高度的逻辑积木

metal layer  = Z 方向的楼层
routing track = 某层楼里的 XY 车道
via          = 楼层之间的匝道

6T / 7.5T    = 用参考金属 pitch 衡量的 cell 高度
              不是金属层数，也不是总线数量

cell 变矮    = 密度更高，但局部布线、电源和 via 更拥挤
BPR / 背面供电 = 把部分供电压力从正面信号布线中释放出来

9. 继续学习时的建议顺序

  1. 先看 INV、NAND2 的 transistor-level schematic；
  2. 再对照同一个门的 standard-cell layout，找出 diffusion、poly、contact、M0/M1；
  3. 然后理解 cell row、power rail、well tie 和 abutment；
  4. 最后再看 6T/7.5T、BPR、backside power 如何改变布局布线约束。

学习时要始终问自己两个问题：

  • 我现在讨论的是 Z 方向换层，还是 同一层 XY 网格里的车道？
  • 这个连接是在 晶体管附近的局部互连，还是已经可以交给更高层的长距离互连？

只要这两个问题分清，很多关于标准单元高度、金属层重叠和先进节点缩放的图就不会再混在一起。
